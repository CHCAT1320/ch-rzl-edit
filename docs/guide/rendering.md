# 预览与渲染规则

本页描述编辑器如何把谱面数据映射到画面。实现以 Rust 参考播放器 `re-ch-rzl-rust` 为准，便于在编辑器中看到与播放器一致的画面。

## 坐标与时间

- 设计分辨率为 **720 × 1280**（9:16），按窗口大小等比缩放并居中。
- 判定圈固定在视口高度的 **74%** 处。
- `xPosition` 以画面宽度为单位，`0` 是中心；编辑器竖线标签即为该值（例如 `-0.25`、`0.25`）。
- 时间统一使用 **tick**。tick 与秒的换算由基础 BPM 与 `bpmShifts` 决定。
- `floorPosition` 是渲染使用的缓存值，由 BPM 变化、Canvas 流速关键帧重新推导，不是独立的时间来源。

线节点位置：

```text
x = (xPosition + canvasX + cameraX) × cameraScale × 视口宽度
y = 判定圈Y − (floorPosition − canvasFloor) × cameraScale × 流速系数 × 视口高度
```

音符的 X 由所在线段的两个节点按 `easeType` 插值得到，Y 由 `floorPosition` 与 Canvas 流速决定。Camera X 关键帧在渲染时取反后参与计算。

## 缓动

所有 `easeType` 取值为 0–18：

| 值 | 名称 |
| --- | --- |
| 0 | linear |
| 1–3 | quadIn / quadOut / quadInOut |
| 4–6 | cubicIn / cubicOut / cubicInOut |
| 7–9 | quartIn / quartOut / quartInOut |
| 10–12 | quintIn / quintOut / quintInOut |
| 13 | constZero |
| 14 | constOne |
| 15–16 | circIn / circOut |
| 17–18 | sineOut / sineIn |

缓动同时作用于线节点之间的 X 插值、关键帧插值和部分游戏内动画。

## Camera 与 Canvas 变换

- **Camera Y 偏移**：按画面宽度换算后直接平移画面内容，不受 Camera 缩放影响；正值向下。
- **Camera 旋转**：以判定线中心为轴顺时针旋转谱面内容，单位为度。
- **Canvas Y 偏移**：按画面宽度换算并随 Camera 缩放一起缩放；正值向下。
- **Canvas 旋转**：以 Canvas X 位置、`y=0（判定线）+ Canvas Y 偏移` 为锚点，将 Canvas 内所有元素整体顺时针旋转。
- Camera Y / 旋转只应用于谱面内容（线、音符、判定圈），不应用于打击特效、UI 和 Riztime 过渡遮罩。
- 打击特效在音符经过全部变换后的实际位置生成，特效本身保持屏幕方向，不随 Camera 旋转。
- 判定圈跟随对应线在当前位置的变换结果，因此会随 Camera 旋转、Y 偏移和 Canvas 变换移动。
- Canvas 序号使用 Canvas X 位置，加上 Canvas Y 偏移，并旋转到与 Canvas 相同的角度；Camera 旋转和 Camera Y 不影响序号。

## 音符类型与颜色

| 类型 | 名称 | 绘制 |
| --- | --- | --- |
| 0 | Tap | 主题颜色（theme index 1）填充 + 黑色描边 |
| 1 | Drag | 白色填充 + 黑色描边 |
| 2 | Hold | 头部为空心圆，主体按主题颜色渐变到白色 |

- 打击特效使用主题的颜色索引 2。
- 判定圈颜色来自每条线的 `judgeRingColor` 关键帧；没有该关键帧时不绘制判定圈。
- 背景色使用主题索引 0。

## 颜色混合

线节点最终颜色 = **节点颜色** 与 **线颜色关键帧** 的混合：

```text
lineColor.a = 0    → 结果 = 节点颜色
lineColor.a = 255  → 结果 RGB = 线颜色 RGB，alpha = 节点 alpha
0 < a < 255        → RGB 线性混合，alpha = 节点 alpha
```

关键点：

- 最终透明度始终取节点颜色的 alpha，所以节点 `a = 0` 的线即使线颜色不透明也不会显示。
- 线颜色关键帧按时间在 `startColor` 与 `endColor` 之间插值。
- 线内部的渐变按屏幕投影位置取色，而不是按时间参数；缓动线段也能保持正确的颜色分布。

## 线条绘制

- 每条线段被拆成 16 小段，每段使用投影中点的颜色填充。
- 线段端点为平头（butt），避免半透明颜色在接缝处叠加变深。
- 线首与线尾额外绘制使用精确节点颜色的圆帽；单点线与零长度线段绘制为圆点。

## 主题与 Riztime

- 没有 Riztime 时使用基础主题（主题 0）。
- 在 Riztime 区间内使用对应主题。
- 进入区间时，挑战主题在一个从底部扩张的圆形遮罩内显示；离开区间时，圆形遮罩向顶部收缩，恢复基础主题。
- 过渡期间，圆外绘制基础主题场景，圆内绘制挑战主题场景。
- 主题、Riztime 时间段按顺序一一配对；编辑其中一个会同步维护另一个。

## 编辑视图与预览视图

- **编辑视图**（`U` 可切换）会叠加：
  - 半透明黑色遮罩；
  - 横线 / 竖线网格与 tick / 秒标签；
  - 固定播放头；
  - 线节点手柄、选中高亮、框选框、粘贴预览。
- **预览视图**（按住 `T`）关闭编辑叠加层，按播放器规则绘制谱面、判定圈、打击特效，并播放打击音效。
- 网格、播放头与关键帧轨道保持屏幕对齐；可编辑的线、节点和音符始终应用 Canvas 旋转，播放音频时也应用 Canvas Y 偏移（cvsMY），暂停编辑时不应用，避免编辑元素上下移动。
- 渲染出的谱面内容（编辑窗口中的预览画面和 `T` 预览）应用完整的 Canvas Y 偏移，播放时编辑内容与预览画面保持一致。
- 编辑视图中的线颜色同样遵循真实谱面颜色与 alpha，因此不可见的线在编辑视图中也不会画出线条，但仍保留节点手柄以便选中编辑。
