# 界面与使用方法

## 界面总览

编辑器由三部分组成：

1. **顶部工具栏**：导入谱面、新建谱面、导入音乐、导出谱面，当前 Canvas 与编辑对象模式。
2. **左侧画布**：9:16 的谱面视口。编辑模式下会叠加网格、播放头、线/音符手柄和 Canvas 序号。
3. **右侧编辑栏**：音频播放器、视图参数，以及 BPM / 主题 / Riztime / 线条 / 对象属性面板。

## 顶部工具栏

| 按钮 | 说明 |
| --- | --- |
| 导入谱面 | 读取谱面 JSON。导入后会禁用导入/新建按钮，避免覆盖当前谱面。 |
| 新建谱面 | 选择音乐后创建基础谱面：默认 BPM 120、一个 Canvas、一个基础主题。 |
| 导入音乐 | 单独替换当前音乐。支持 mp3 / wav / ogg / flac / m4a / aac / opus。 |
| 导出谱面 | 对当前谱面做字段清洗后导出 JSON；空线会被移除。 |
| 当前 Canvas | 切换要编辑的 Canvas。删除 Canvas 后序号会自动回退。 |
| 新建 Canvas | 追加一个 Canvas，默认 X 关键帧为 0、流速关键帧为 1。 |
| 删除当前 Canvas | 删除该 Canvas，并移除其上的线节点；其余节点与 Hold 结束 Canvas 的序号前移。至少保留一个 Canvas。 |
| 编辑对象 | 切换 `line&note` / `cvsMX` / `cvsMY` / `cvsSpeed` / `cvsRot` / `cameraX` / `cameraY` / `cameraScale` / `cameraRot` 编辑模式。 |

## 右侧编辑栏

### 播放与视图

- **音频播放器**：播放 / 暂停、进度拖动、音量。空格键同样可以播放 / 暂停。
- **流速**（0–30）：编辑视图的纵向滚动速度，同时影响预览中的谱面速度表现。
- **横线密度**（4–256）：每一 tick 内的横线数量，也决定网格吸附与滚轮跳转步长。
- **竖线密度**（2–128）：X 方向网格密度，用于对齐 `xPosition`。
- **编辑 X 偏移**（-2–2）：只影响编辑视图的水平偏移，便于查看边缘对象，不会写入谱面。
- **显示 Canvas Index**：在画布上显示当前可见的 Canvas 序号。
- **滚轮**：以 `60 / (基础 BPM × 横线密度)` 秒为步长跳转音频时间。

### BPM 面板

- **基础 BPM**：谱面的基准 BPM（1–999）。
- **BPM 变化**：每个条目包含「时间 tick」和「实际 BPM」。文件内部保存的是倍率 `value = 实际 BPM / 基础 BPM`。
- 新增的 BPM 变化默认在 tick 0、倍率 1。

### 主题面板

每个主题包含 3 个颜色：

| 索引 | 用途 |
| --- | --- |
| 0 | 背景色 |
| 1 | Note 颜色（Tap / Hold 填充） |
| 2 | 特效颜色（打击特效等） |

主题 0 是基础主题。新增主题会同时新增一个 Riztime 时间段，二者按顺序配对；删除主题会同时删除对应时间段，反之亦然。

### Riztime 面板

每个时间段包含：

- **开始 tick** / **结束 tick**：主题生效区间。
- **过渡秒**：进入和离开该区间时，圆形遮罩过渡的时长。

导入的谱面如果带有 `checkPoint` 字段，会在导出时保留，但当前界面不提供编辑。

### 线条面板

需要先选中一条线才会启用。面板中可以编辑：

- **线颜色关键帧**：时间 tick、起始色、结束色。
- **判定圈关键帧**：时间 tick、起始色、结束色。

关键帧时间不能早于该线第一个节点的 tick。颜色插值与混合规则见 [预览与渲染规则](/guide/rendering#颜色混合)。

::: warning 线颜色与透明度
线颜色的最终 alpha 取**节点颜色**的 alpha。线颜色关键帧的 alpha 只决定“覆盖强度”：

- `a = 0`：完全使用节点颜色；
- `a = 255`：使用关键帧 RGB，但保留节点颜色的 alpha；
- `0 < a < 255`：按比例混合 RGB，最终 alpha 仍取节点颜色。

因此，节点 alpha 为 0 的线即使设置了不透明的线颜色，也不会显示。
:::

### 对象面板

显示当前选中对象的可编辑字段：

- **线节点**：时间 tick、X、Canvas、缓动类型、节点颜色。
- **音符**：开始 tick、类型（0 Tap / 1 Drag / 2 Hold）；Hold 额外提供结束 tick 与结束 Canvas。
- **Canvas / Camera 关键帧**：时间 tick、值、缓动（Canvas 流速不提供缓动字段）。
- **线条**：显示节点数与音符数摘要。

::: tip 数值范围
`xPosition` 输入范围为 -4–4；Canvas X / Y、Camera X / Y 关键帧值为 -4–4；Canvas 流速 / Camera 缩放关键帧值为 -10–10；旋转关键帧为 -360°–360°；Canvas 序号限制在现有 Canvas 范围内。
:::

## Camera / Canvas 变换事件

编辑对象下拉框中的以下模式用于编辑整体变换事件：

| 模式 | 作用 |
| --- | --- |
| `cvsMY` | Canvas 整体 Y 偏移关键帧 |
| `cvsRot` | Canvas 整体旋转关键帧 |
| `cameraY` | Camera 垂直偏移关键帧 |
| `cameraRot` | Camera 旋转关键帧 |

- **Y 偏移**：单位与 `xPosition` 相同（画面宽度），正值让内容向下移动。Camera Y 偏移不受 Camera 缩放影响。
- **旋转**：单位为度，正值顺时针。Camera 绕判定线中心旋转；Canvas 内的所有元素以 Canvas X、`y=0（判定线）+ Canvas Y 偏移` 为锚点整体旋转。
- 变换作用于预览场景（编辑模式下网格下方的渲染内容）；编辑叠加层保持原始谱面坐标，便于编辑。
- **Camera Y / 旋转**只作用于谱面内容（线、音符、判定圈），不作用于打击特效、UI 和 Riztime 过渡遮罩。
- **Canvas Y / 旋转**在预览中作用于该 Canvas 上的内容；Canvas 序号会跟随 Canvas Y 偏移，并始终旋转到与 Canvas 相同的角度。
- 打击特效生成在音符经过全部变换后的实际位置，但特效本身不会被旋转。
- 判定圈绘制在对应线当前时刻的位置上，因此会随 Camera 和 Canvas 的变换移动。

## 画布操作

### 选择

- 单击对象进行选择；命中优先级为 **Hold 身体 > 音符 > 线节点 > 线条**。
- 音符与线节点重叠时，点击会优先选中音符；要编辑节点，可先点击线条或其他空白位置后再精调。
- 点击空白区域会清空选择。
- 按住 `Shift` 切换到框选模式，再拖拽矩形框选。框选只作用于当前 Canvas 上的对象。
- 多选时所有被选中的线节点、音符和关键帧都会高亮。

### 拖动

按住选中的对象拖动即可修改：

- **线节点**：同时修改 tick 与 `xPosition`，拖动后按 tick 重新排序。
- **音符**：只修改时间，X 由所在线自动插值；Hold 的结束时间会被限制在开始时间之后、线的范围之内。
- **Canvas / Camera 关键帧**：修改时间与值。

拖动结束会写入撤销栈。

### 添加对象

| 快捷键 | 模式 | 行为 |
| --- | --- | --- |
| `R` | `line&note` | 在鼠标位置添加线节点；若已选中线则追加到该线，否则新建一条线。 |
| `R` | 其它模式 | 在鼠标位置添加当前类型的关键帧；同一 tick 已有关键帧时改为选中它。 |
| `Q` | `line&note` | 添加 Tap。需要先选中一条至少有两个节点的线。 |
| `W` | `line&note` | 添加 Drag。 |
| `E` | `line&note` | 添加 Hold，默认结束时间为开始 tick + 1，并限制在线范围内。 |

新建线节点会继承同线中前一个节点的颜色与缓动；新线默认白色、线性缓动。

### 复制、粘贴与撤销

- `Ctrl+C` 复制当前选择并进入粘贴预览；移动鼠标可看到半透明预览。
- `Ctrl+V` 应用粘贴。复制/剪切后已处于预览状态；若当前不在预览状态，第一次 `Ctrl+V` 只进入预览，第二次才应用。
- `Ctrl+X` 剪切并进入粘贴预览。
- `Ctrl+B` 切换镜像粘贴（以复制时的原点水平镜像）。
- `Ctrl+Z` 撤销，最多保留 50 步。
- `Delete` 删除当前选择（多选时删除全部选中对象）。

### 批量生成流速缓动

在 `cvsSpeed` 模式：

1. 框选起始和结束两个流速关键帧；
2. 在对象面板选择缓动类型；
3. 点击 **按横线生成缓动关键点**。

编辑器会按横线密度在两点之间生成中间关键帧，并删除区间内部原有的流速关键帧。

## 预览

- **按住 `T`**：从当前音频时间开始预览播放；松开 `T`、窗口失焦或预览结束时，会暂停并恢复到预览前的时间点。
- 预览包含判定圈、打击特效、打击音与 Riztime 主题过渡。
- 需要先导入音乐；没有音乐时 `T` 不会启动预览。
- `U` 切换编辑叠加层显示（编辑模式开关），便于在编辑网格与纯渲染之间切换。

## 导入与导出

- 导入时直接使用谱面 JSON 的原始字段；渲染与编辑过程中会重新计算 `floorPosition` 等缓存字段。
- 导出时会做统一清洗：
  - 补齐 `fileVersion`、`songsName`、`bPM`、`offset`；
  - 规范化颜色到 0–255；
  - 保证每个 Canvas / Camera 至少有两个关键帧；
  - 保证 Hold 的 `otherInformations` 至少包含结束 tick、结束 Canvas、结束 `floorPosition`；非 Hold 音符统一写为 `[]`（读取时允许缺失该键）；
  - 为音符补 `isHited: false`；
  - 移除没有线节点的线。
- 浏览器模式优先使用 `showSaveFilePicker`，不支持时回退为下载 `chart.json`。
