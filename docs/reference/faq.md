# 常见问题

## 为什么点了线节点却选中了音符？

单击命中优先级为 **Hold 身体 > 音符 > 线节点 > 线条**。音符通常正好位于线节点上，因此会优先选中音符。

需要编辑被音符覆盖的线节点时，可以使用 `Shift` 框选：框选会把范围内的节点和音符一起选中，节点仍然可以拖动。

## 为什么线或节点看不见？

检查节点颜色的 alpha：

- 线颜色的最终 alpha 取节点颜色的 alpha；节点 `a = 0` 时整条线不可见。
- 节点 `a` 较小（例如半透明）时，线与判定圈也会相应变淡。
- 线颜色关键帧的 alpha 只控制覆盖强度，不控制最终透明度。
- 判定圈需要该线存在 `judgeRingColor` 关键帧才会绘制。

## 为什么导出的谱面里没有某条线？

导出会移除没有 `linePoints` 的线。只添加了音符但没有线节点的线不会保留。

## 为什么修改了 BPM 或流速后位置变了？

音符的 Y 位置依赖 `floorPosition`，而 `floorPosition` 由 BPM 与 Canvas 流速推导。修改 BPM 变化或流速关键帧后，受影响的线节点、音符与 Hold 结束位置都会重新计算。

手工编辑 JSON 时，`floorPosition` 可以填 0，导入后编辑器会重新计算。

## 为什么 `T` 预览没有反应？

- 需要先导入音乐。
- `T` 是“按住预览”，松开即结束；按住键盘期间 `event.repeat` 不会重复触发。
- 浏览器中首次播放可能需要用户手势解锁音频；先按 `Space` 播放一次通常可以解决。

## 浏览器里没有系统文件对话框怎么办？

没有 Tauri API 时会自动回退：

- 导入：使用 `<input type="file">` 文件选择器。
- 导出：优先使用 `showSaveFilePicker`，不支持时下载 `chart.json`。

## 为什么新谱面按钮点了没反应？

导入或新建过谱面后，「导入谱面」和「新建谱面」会被禁用，避免覆盖当前内容。刷新页面即可重新开始。

## 为什么开发端口不是默认的 5173？

`vite.config.ts` 为 Tauri 固定了 **1420** 端口并启用 `strictPort`。端口被占用时 Vite 会直接报错，请先释放 1420 端口。

## `tauri dev` 报找不到 `bun`？

Tauri 配置中的 `beforeDevCommand` / `beforeBuildCommand` 使用 `bun run`。安装 Bun，或自行修改 `src-tauri/tauri.conf.json` 为对应的包管理器命令。

## 编辑视图和参考播放器仍有细微差异怎么办？

请优先确认：

1. 当前时间是否一致（音频进度、`offset`、BPM 变化）；
2. 节点与线颜色的 alpha；
3. 是否处于 Riztime 过渡区间；
4. 是否使用了缓动线段；
5. 导入的 `floorPosition` 是否被旧数据覆盖（编辑器会重新推导）。

渲染逻辑以 `re-ch-rzl-rust` 为参考；如发现差异，建议附上谱面时间点、对象索引与截图。
