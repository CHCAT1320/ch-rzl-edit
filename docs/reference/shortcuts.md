# 快捷键一览

## 播放与预览

| 快捷键 | 作用 |
| --- | --- |
| `Space` | 播放 / 暂停音频。焦点在输入框时也会生效并先移除焦点。 |
| 按住 `T` | 从当前时间开始预览；松开后暂停并恢复预览前的时间点。 |
| `U` | 切换编辑叠加层（网格、手柄、播放头）。 |
| 鼠标滚轮 | 按 `60 / (基础 BPM × 横线密度)` 秒跳转音频时间。 |
| `F12` | 打开 / 关闭 DevTools（Tauri 桌面端）。 |

## 编辑

| 快捷键 | 作用 |
| --- | --- |
| `R` | `line&note`：添加线节点；其它模式：添加关键帧。 |
| `Q` | 添加 Tap（需要选中一条至少有两个节点的线）。 |
| `W` | 添加 Drag。 |
| `E` | 添加 Hold。 |
| `Delete` | 删除当前选择（含多选）。 |
| `Ctrl+Z` | 撤销，最多 50 步。 |
| `Ctrl+C` | 复制选择并进入粘贴预览。 |
| `Ctrl+X` | 剪切选择并进入粘贴预览。 |
| `Ctrl+V` | 应用粘贴；若当前不在粘贴预览状态，第一次按下只进入预览。 |
| `Ctrl+B` | 切换镜像粘贴。 |
| `Shift` | 切换框选模式。再次按下退出。 |

## 鼠标

| 操作 | 作用 |
| --- | --- |
| 左键单击 | 选择对象；点击空白清空选择。 |
| 左键拖动 | 移动线节点、音符或关键帧。 |
| `Shift` + 拖拽 | 框选当前 Canvas 上的对象。 |
| 拖动音频进度条 | 跳转播放位置。 |

::: tip 输入框中的快捷键
除 `Space` 外，焦点位于 `input` / `textarea` / `select` 时不会触发编辑器快捷键，避免与数值输入冲突。
:::
